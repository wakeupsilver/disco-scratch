🪩 Disco Scratch

A neon-disco block-coding editor that runs inside Scratch: nesting blocks, threads, custom blocks and 12 extensions.

⛶ Open full screen ⬇ Download .sb3

How to play

  1. Click the green flag to start the editor.
  2. Drag blocks from the palette into the code area; click a block to run it.
  3. File → Examples… loads 8 ready-made projects.
  4. Click the ➕ button (bottom left) for extensions; click the disco ball to toggle party mode.
Runs in your browser with TurboWarp, a Scratch player. To open it in Scratch itself: download the .sb3, go to scratch.mit.edu, then File → Load from your computer and click the green flag.
